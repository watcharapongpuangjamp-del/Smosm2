# 📱 Smart OSM Next (ระบบทะเบียนประชากรและสุขภาพชุมชน อสม.)

ระบบ Smart OSM Next สำหรับอาสาสมัครสาธารณสุขประจำหมู่บ้าน (อสม.), โรงพยาบาลส่งเสริมสุขภาพตำบล (รพ.สต.), และเจ้าหน้าที่สาธารณสุข สำหรับจัดการข้อมูลครัวเรือน ทะเบียนประชากร แผนที่สุขภาพชุมชน (GIS) และการรายงานผลงาน อสม. 1 ประจำเดือน

---

## 🌟 ฟีเจอร์หลัก (Key Features)

- **ทะเบียนประชากร (Population Registry)**:
  - ตรวจสอบเลขประจำตัวประชาชน 13 หลักด้วยอัลกอริทึม Checksum ตามมาตรฐานกรมการปกครอง
  - คำนวณอายุและวันเกิดอัตโนมัติ
  - การจำแนกตามภาวะพึ่งพิง 3 ติด (ติดสังคม / ติดบ้าน / ติดเตียง ตามเกณฑ์ Barthel ADL)
  - คัดกรองและติดตามโรคไม่ติดต่อเรื้อรัง (NCDs เช่น ความดันโลหิตสูง, เบาหวานชนิดที่ 2, โรคไต)

- **จัดการหลังคาเรือน (Household Management)**:
  - บันทึกข้อมูลบ้านเลขที่, เจ้าบ้าน, และ อสม. ผู้รับผิดชอบดูแล
  - ตรวจสอบและบันทึกดัชนีลูกน้ำยุงลาย (House Index - HI %)
  - ประเมินระดับสุขาภิบาล แหล่งน้ำบริโภค และการกำจัดขยะ

- **แผนที่สุขภาพชุมชน GIS (OpenStreetMap)**:
  - แสดงพิกัดตำแหน่งหลังคาเรือนแยกสีตามระดับความเสี่ยง (ติดเตียง/พบลูกน้ำ = สีแดง, ติดบ้าน/โรคเรื้อรัง = สีส้ม, ปกติ = สีเขียว)
  - คลิกบนแผนที่เพื่อดึงพิกัด GPS สำหรับปักหมุดเพิ่มหลังคาเรือนใหม่

- **การคัดกรองสุขภาพและเยี่ยมบ้าน (Health Screening)**:
  - บันทึกความดันโลหิต (Sys/Dia พร้อมประเมินเกณฑ์ความดันสูงอัตโนมัติ)
  - ค่าน้ำตาลในเลือด DTX, ส่วนสูง/น้ำหนักและคำนวณ BMI ตามเกณฑ์เอเชีย
  - ระบบแจ้งเตือนเคสผิดปกติที่ต้องส่งต่อ รพ.สต.

- **รายงาน อสม. 1 ประจำเดือน & ทำเนียบ อสม.**:
  - รวบรวมสถิติรายเดือนอัตโนมัติสำหรับส่ง รพ.สต.
  - รองรับการพิมพ์รายงานและส่งออกเป็นไฟล์ Excel

- **นำเข้าและส่งออกข้อมูล (Excel / CSV / JSON)**:
  - ส่งออกข้อมูลเป็นไฟล์ Excel (.xlsx) และสำรองข้อมูล JSON
  - มีแม่แบบ Excel Template สำหรับนำเข้าข้อมูลประชากรพร้อมใช้งาน

## 🤖 ระบบ Build Android APK อัตโนมัติ (CI/CD GitHub Actions)

โปรเจกต์นี้มี Workflow สำหรับ Build Android APK แบบเต็มรูปแบบอยู่ที่:
`.github/workflows/build-apk.yml`

### 1. วิธีสั่ง Build APK บน GitHub:
1. ไปที่แท็บ **Actions** ใน GitHub Repository ของคุณ
2. เลือก Workflow **"Build Android APK & Release"** ทางซ้ายมือ
3. กดปุ่ม **Run workflow**:
   - เลือก Branch (`main` หรือ `develop`)
   - เลือกประเภท Build: `both` (ทั้ง Debug และ Release), `debug`, หรือ `release`
   - เลือกตัวเลือก `create_release: true` หากต้องการให้สร้าง Release หน้า GitHub พร้อมไฟล์ดาวน์โหลด
4. กด **Run workflow** สีเขียว

### 2. วิธีดาวน์โหลด APK หลัง Build เสร็จ:
- **จากแท็บ Actions**: คลิกเข้าไปที่รอบการทำงานที่สำเร็จ เลื่อนลงมาที่หัวข้อ **Artifacts** จะพบไฟล์ zip ของ APK ให้กดดาวน์โหลดได้ทันที
- **จากแท็บ Releases**: หากเปิดตัวเลือก Release ไว้ สามารถดาวน์โหลดไฟล์ `.apk` โดยตรงจากหน้า Releases ของ Repository

### 3. การตั้งค่า Release Keystore สำหรับ Production (ตัวเลือกเสริม):
หากต้องการใช้ Keystore ส่วนตัวสำหรับอัปโหลดขึ้น Google Play Store ให้ตั้งค่าใน **Settings > Secrets and variables > Actions**:
- `RELEASE_KEYSTORE_BASE64`: ไฟล์ `.jks` แปลงเป็น Base64
- `STORE_PASSWORD`: รหัสผ่าน Store
- `KEY_ALIAS`: ชื่อ Alias ของ Key
- `KEY_PASSWORD`: รหัสผ่าน Key
*(หากไม่ได้ตั้งค่าไว้ Workflow จะสร้าง Fallback Signing Key สำหรับติดตั้งและทดสอบให้โดยอัตโนมัติ)*
